Assignment 1 - Hello World: GitHub and d3  
===

Project Description
--- 

For this assignment, I created a cityscape with an interactive component for changing the time of day using HTML, CSS, JavaScript, and D3.js. The visualization shows a city with buildings, windows, mountains, a road, and a sun.

The user can click a button to switch between daytime and nighttime. When switching to night, the sky becomes darker, stars appear, the sun changes into a moon, and the building windows light up.

The project uses SVG shapes, including rectangles for the buildings, circles for the sun, polygons for the stars, lines for the road markings, and a path for the mountains.

Technical Achievement
---

For my technical achievement, I used D3 transitions to create an interactive day and night animation. Instead of changing instantly, the colors and other properties transition over one second. I also used arrays and loops to generate multiple buildings and windows rather than creating each shape individually.

Design Achievement
---

For my design achievement, I created a cityscape using a consistent color palette and multiple layers of shapes. I used lighter colors for the sunset and darker colors for nighttime. I also gave the buildings different heights and added details like windows, mountains, and road markings to make the scene more interesting.
